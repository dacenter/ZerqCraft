# 🎮 ZerqCraft Gaming Hub

**Игровой центр с 8 мультитач играми для больших сенсорных экранов (50")**

## 🌟 Особенности

- ✅ **8 разных игр** с уникальной механикой и стилями
- 🖐️ **Полная мультитач поддержка** - до 10 одновременных касаний
- 👥 **Мультиплеер** - от 1 до 6 игроков одновременно
- 🎨 **Красивая графика** с анимациями и эффектами частиц
- 🏆 **Таблица рекордов** для каждой игры
- 📱 **Адаптивный дизайн** под любой размер экрана
- 🔊 **Звуковые эффекты** и вибрация (опционально)

## 🎯 Список игр

### 1. 🍎 Fruit Slash (Аркада)
**Игроки:** 1-4 | **Описание:** Рубите летающие фрукты пальцами! Избегайте бомб и набирайте комбо.

### 2. 🏒 Air Hockey (Спорт)
**Игроки:** 2 | **Описание:** Классический воздушный хоккей. Первый до 7 голов побеждает!

### 3. 🎨 Color Splash (Творчество)
**Игроки:** 1-6 | **Описание:** Свободное рисование красками. Смешивайте цвета, создавайте шедевры!

### 4. 🎹 Piano Hero (Музыка)
**Игроки:** 1-2 | **Описание:** Нажимайте на падающие плитки в ритм! Система точности и комбо.

### 5. 🧩 Memory Match (Головоломка)
**Игроки:** 1-4 | **Описание:** Найдите все пары карточек. Тренируйте память!

### 6. 🔨 Whack-a-Mole (Реакция)
**Игроки:** 1-4 | **Описание:** Успейте ударить всех кротов за 60 секунд!

### 7. 🫧 Bubble Pop (Казуальная)
**Игроки:** 1-6 | **Описание:** Лопайте цветные пузыри! Чем больше подряд - тем больше комбо.

### 8. 🚀 Space Defender (Шутер)
**Игроки:** 1-4 | **Описание:** Защищайте планету от космических захватчиков! Кооператив.

## 🚀 Быстрый старт

Просто откройте `index.html` в браузере:

```bash
# Простой способ
open index.html

# Или запустите локальный сервер
python -m http.server 8000
# Затем откройте http://localhost:8000
```

## ⚙️ Настройки

- **🔊 Громкость звуков** - 0-100%
- **🎵 Громкость музыки** - 0-100%
- **📳 Вибрация** - вкл/выкл

Все настройки сохраняются в localStorage браузера.

## 🎨 Технологии

- **HTML5 Canvas** - рендеринг игр
- **Vanilla JavaScript** - без зависимостей
- **CSS3 Animations** - UI эффекты
- **Touch Events API** - мультитач

- **Оптимизированный Canvas** рендеринг
- **Минимальное использование памяти**
