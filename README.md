# Telegram Bot - Повышенная стипендия СГТУ

Telegram бот для подачи и обработки заявок на повышенную государственную академическую стипендию СГТУ им. Гагарина Ю.А.

## Возможности

### Для студентов:
- Регистрация по ФИО (проверка по списку допущенных)
- Подача заявки на 4 типа стипендий:
  - Научная деятельность
  - Спортивные достижения
  - Творческая деятельность
  - Общественная деятельность
- Загрузка документов (таблица достижений, грамоты, рекомендательные письма)
- Автоматический расчёт предварительных баллов
- Отслеживание статуса заявки

### Для администратора:
- Статистика по заявкам
- Просмотр всех заявок с фильтрацией по статусу
- Просмотр загруженных документов
- Одобрение/отклонение заявок
- Добавление комментариев и замечаний
- Отправка сообщений студентам
- Поиск по ФИО
- Экспорт в CSV

## Установка

### 1. Клонирование репозитория
```bash
git clone <repo_url>
cd ZerqCraft
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
```

**Как получить токен бота:**
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

**Как узнать свой Telegram ID:**
1. Напишите @userinfobot в Telegram
2. Скопируйте ваш ID

### 5. Настройка списка студентов

Отредактируйте `bot/config.py`, добавив ФИО студентов в `ALLOWED_STUDENTS`:
```python
ALLOWED_STUDENTS = [
    "Иванов Иван Иванович",
    "Петрова Мария Сергеевна",
    # ...
]
```

### 6. Запуск бота
```bash
python main.py
```

## Использование

### Команды для студентов:
- `/start` - Начало работы / регистрация

### Меню студента:
- "Новая заявка" - Создать заявку на стипендию
- "Мои заявки" - Просмотр своих заявок
- "Таблица баллов" - Посмотреть баллы за достижения
- "Помощь" - Справка

### Команды для админа:
- `/admin` - Открыть админ-панель

### Меню админа:
- "Статистика" - Общая статистика
- "Все заявки" - Список всех заявок
- "Студенты" - Список студентов
- "Поиск" - Поиск по ФИО
- "На рассмотрении" / "Одобренные" / "Отклонённые" - Фильтры
- "Экспорт" - Выгрузка в CSV

## Система баллов

Баллы начисляются согласно положению о стипендиальном обеспечении СГТУ:

### Научная деятельность:
- Публикация Scopus/WoS: 50 б.
- Публикация ВАК: 35 б.
- Публикация РИНЦ: 20 б.
- 1 место межд. конференция: 50 б.
- Регистрация программы для ЭВМ: 30 б.
- И другие...

### Спортивные достижения:
- 1 место международные: 50 б.
- 1 место всероссийские: 40 б.
- Мастер спорта: 50 б.
- И другие...

### Творческая деятельность:
- 1 место международный конкурс: 50 б.
- 1 место всероссийский: 40 б.
- И другие...

### Общественная деятельность:
- Организатор волонтёрства: 25 б.
- Руководитель студсовета: 30 б.
- Благодарность ректора: 20 б.
- И другие...

Полный список баллов в файле `bot/utils/scoring.py`.

## База данных

Используется SQLite. База создаётся автоматически при первом запуске.

Таблицы:
- `students` - Студенты
- `applications` - Заявки
- `documents` - Загруженные документы
- `achievements` - Достижения
- `messages` - История сообщений

## Технологии

- Python 3.10+
- aiogram 3.x - Telegram Bot API
- aiosqlite - Асинхронная работа с SQLite
- python-dotenv - Переменные окружения
