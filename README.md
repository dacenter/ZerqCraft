# MeteoData Big Data Landscape

## Курсовая работа по дисциплине «Анализ больших данных»

Big Data ландшафт для обработки метеоданных, поступающих со станций.

## Предметная область

**Обработка метеоданных, поступающих со станций** — система сбора, хранения и анализа метеорологических данных от распределенной сети погодных станций.

### Задачи, требующие Big Data технологий:

1. **Хранение исторических данных** — петабайты данных от тысяч станций за десятилетия
2. **Потоковая обработка** — анализ данных в реальном времени для раннего предупреждения
3. **Статистический анализ** — выявление климатических паттернов и аномалий
4. **Прогнозирование** — построение моделей на основе исторических данных

## Компоненты

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Хранилище | HDFS | Распределенное хранение исторических данных |
| Batch-обработка | MapReduce | Статистический анализ больших объемов данных |
| SQL-аналитика | Spark SQL | Ad-hoc запросы и построение отчетов |
| Потоковая обработка | Spark Streaming | Анализ данных в реальном времени |
| Брокер сообщений | Apache Kafka | Буферизация и маршрутизация потоков данных |
| Time-series DB | InfluxDB | Хранение временных рядов для быстрых запросов |

## Быстрый старт

### 1. Запуск Hadoop кластера
```bash
cd hadoop
docker-compose up -d
```

### 2. Запуск Kafka
```bash
cd kafka
docker-compose up -d
```

### 3. Запуск эмуляторов станций
```bash
cd emulators
python weather_station_emulator.py
```

### 4. Запуск Spark Streaming
```bash
cd spark-streaming
spark-submit --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.0 weather_stream_processor.py
```
