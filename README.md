# Укек - Telegram Бот

Telegram бот "Серафим" - виртуальный гид по золотоордынскому городу Укек.

## Возможности

- Отвечает на вопросы про город Укек и археологию
- Рассказывает историю Золотой Орды
- Обрабатывает фотографии
- Понимает голосовые сообщения
- Помнит контекст разговора

## Установка

1. Создай бота у @BotFather в Telegram и получи токен

2. Создай `.env` файл:
```bash
cp .env.example .env
```

3. Впиши токен в `.env`:
```
BOT_TOKEN=твой_токен_от_botfather
```

4. Установи зависимости:
```bash
pip install -r requirements.txt
```

5. Запусти:
```bash
python main.py
```

## База знаний

Редактируй файл `knowledge.txt` чтобы добавить свои вопросы и ответы.

## Команды бота

- `/start` - начать разговор
- `/help` - справка
- `/clear` - очистить историю
