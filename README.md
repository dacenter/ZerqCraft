# Telegram Bot - Повышенная стипендия СГТУ

Telegram бот с **AI-анализом** для подачи заявок на повышенную государственную академическую стипендию СГТУ им. Гагарина Ю.А.

## Возможности

### Для студентов:
- Регистрация по ФИО (проверка по списку)
- **Отправка одного архива** со всеми документами
- **AI автоматически анализирует:**
  - Таблицу достижений
  - Грамоты и сертификаты
  - **Сверяет соответствие** таблицы и грамот
  - **Рассчитывает баллы** по положению
  - Выявляет несоответствия и ошибки
- Отслеживание статуса заявки

### Для администратора:
- Просмотр результатов AI-анализа
- Повторный анализ документов
- Одобрение/отклонение заявок
- Отправка сообщений студентам
- Экспорт в CSV

## Установка

### 1. Установка зависимостей

```bash
# Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/Mac

# Установить пакеты
pip install -r requirements.txt
```

**Для Mac** также нужен poppler для работы с PDF:
```bash
brew install poppler
```

**Для Linux:**
```bash
sudo apt-get install poppler-utils
```

### 2. Настройка

Создайте файл `.env`:
```bash
cp .env.example .env
nano .env
```

Заполните:
```
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_telegram_id
ANTHROPIC_API_KEY=ваш_ключ_anthropic
```

**Как получить Anthropic API Key:**
1. Зайдите на https://console.anthropic.com
2. Зарегистрируйтесь
3. Пополните баланс (минимум $5)
4. Создайте API ключ в Settings -> API Keys

### 3. Запуск

```bash
python main.py
```

## Как пользоваться

### Студент:
1. Напишите боту `/start`
2. Введите ФИО
3. Отправьте **ZIP-архив** с документами:
   - Таблица достижений (PDF или фото)
   - Все грамоты/сертификаты
   - Рекомендательные письма
4. Нажмите "Готово - Анализировать"
5. AI проанализирует и выдаст результат

### Администратор:
1. Напишите `/admin`
2. Просматривайте заявки с результатами AI
3. Одобряйте/отклоняйте

## Что проверяет AI:

1. **Извлекает данные** из таблицы достижений
2. **Сверяет с грамотами** - есть ли подтверждение каждого достижения
3. **Проверяет соответствие** - совпадают ли даты, названия, результаты
4. **Считает баллы** по системе СГТУ
5. **Выдаёт два балла:**
   - Заявленные (что написано в таблице)
   - Подтверждённые (только то, что подтверждено грамотами)

## Стоимость

Один анализ (10-20 изображений) ≈ $0.05-0.15 через Anthropic API.
